# Article Writer Skill

## Purpose
キーワードから SEO 最適化された技術記事を生成する。

## Target
- 文字数: 3,000〜5,000文字
- H2見出し: 4〜6個
- コードブロック: 最低1つ

## Style Rules
- ですます調
- 1文60文字以内を目安
- 専門用語は初出時に説明
- 具体例を各セクションに1つ以上
- 断定する（「〜だと思います」は使わない）

## SEO Rules
- キーワードをタイトル・H2の1つ・冒頭100文字に含める
- 関連キーワードを自然に散りばめる
- 画像のalt属性にキーワードを含める

## Structure Template
```
# {title}

{冒頭フック: 読者の課題を明示 + 結論を先出し}

## {H2-1: 概念の説明}
{本文 + コード例}

## {H2-2: 実装手順}
{ステップバイステップ + コード}

## {H2-3: 実践Tips / 注意点}
{具体的なTips}

## {H2-4: まとめ}
{要点3行 + 次のアクション}
```

## Forbidden
- 「この記事では〜を解説します」で始めない
- 「いかがでしたか？」で終わらない
- 「近年、〜が注目されています」
- 「それでは早速見ていきましょう」
- AI Slop表現全般（harness/rules/ai-slop.md参照）
